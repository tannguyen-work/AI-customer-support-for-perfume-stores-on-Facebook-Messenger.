# AI-customer-support-for-perfume-stores-on-Facebook-Messenger.
This university project uses AI to store product and inventory information, then automatically support and advise customers through Facebook comments and Messenger chats. The system reduces waiting time, prevents missed customers, and provides backup support when the customer service team has problems.
